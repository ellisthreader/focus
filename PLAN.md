# Focus Personal OS Plan

The reviewed transformation plan is split into focused documents:

1. [Product and implementation architecture](docs/plans/01-product-architecture.md)
2. [Strict plan review and scope corrections](docs/plans/02-plan-review.md)
3. [Information architecture and interaction model](docs/plans/03-information-architecture.md)
4. [Accessibility and keyboard contract](docs/plans/04-accessibility-and-keyboard.md)
5. [Test and release strategy](docs/plans/05-test-and-release-strategy.md)

## Implemented First Release

- Local-first v2 schema and legacy migration.
- Today, Calendar, Tasks, Focus, Health, Progress, Timeline, Work, Insights,
  Search, and Settings.
- Restart-safe timer and existing explainable focus model.
- Import/export and optional folder/MySQL sync compatibility.
- Calm light/dark design system and narrow-window layout.
- Keyboard navigation, command search, semantic forms, and reduced motion.

## Deferred Deliberately

- External calendar provider OAuth and recurrence sync.
- Apple Health, Google Health Connect, or medical integrations.
- Multi-user collaboration.
- Cloud AI or medical/productivity causation claims.
- Packaged auto-update infrastructure.
